# pi-customizations

Personal Pi customization package (extensions, skills, prompt templates, and themes).

## Install

From this directory:

```bash
pi install .
```

Then inside Pi:

```bash
/theme my-theme
```

## Contents

- `extensions/` — custom behaviors and commands
- `skills/` — reusable Agent Skills
- `prompts/` — slash-command prompt templates
- `themes/` — custom TUI themes
